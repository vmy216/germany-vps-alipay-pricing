## 哪些人不该买这台机器

**要低延迟的**。游戏加速、远程桌面、实时语音中转，130ms 起步的延迟没法用，香港或日本机房才是正解，多花的钱省不下来。

**流量需求很小的**。一个静态博客一个月跑不了 100GB，GIA 线路的溢价你用不上，便宜档足够。

**需要托管服务的**。这是自助型 VPS，不提供 Windows 授权、独立 IP 段、代运维。系统装坏了只能自己用 VNC 救。

**需要频繁换 IP 的**。官方频道此前公告过 IPv4 资源紧张，美国和德国机房一度暂停受理换 IP 申请。如果你的业务依赖换 IP，下单前先问客服当前政策。
